# Canva Leonardo Tool

PyQt6 desktop tool for account management, Leonardo.ai video generation, and packaged Windows builds with bundled Playwright Chromium.

## Run locally

```bash
pip install -r requirements.txt
python -m playwright install chromium
python main.py
```

## Build

Windows builds are generated by GitHub Actions with PyInstaller. The workflow installs Playwright Chromium into `browsers/` and bundles it into the release zip.
